## 1. 기본 스토리지의 메모리 유형

### 1.1 랜덤 액세스 메모리 [RAM, Random Access Memory]

RAM은 가장 중요한 유형의 메모리로 시스템 앱과 컴퓨터가 현재 관리하고 있는 프로세스를 포함하여 수많은 주요 프로세스를 처리하고 수용하지만 파일이나 앱을 위한 일종의 실행 패드 역할도 한다.

### 1.2 읽기 전용 메모리 [ROM, Read Only Memory]

ROM에서 사용자가 데이터를 확인할 수 있지만 수집된 데이터를 수정할 수 없는 형태로 구성된다. 영구적으로 RAM과 다르기에 컴퓨터가 전원이 `Shut-Down`로 돌입하더라도 데이터가 남아 있기 때문에 비휘발성 스토리지로 의미된다.
